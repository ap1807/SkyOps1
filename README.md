# SkyOps – Airline Passenger Satisfaction System

SkyOps is an end-to-end airline passenger satisfaction system that uses machine learning to predict passenger satisfaction based on passenger, flight, booking, and service-quality attributes.

The project combines a machine learning workflow with frontend and backend components to provide an interactive system for passenger satisfaction prediction and analysis.

## Overview

Airline passenger satisfaction depends on multiple factors, including passenger characteristics, flight details, booking information, and service quality.

SkyOps processes these attributes, applies machine learning techniques, and predicts whether a passenger is satisfied while helping analyze the factors that influence customer experience.

## Features

* Airline passenger satisfaction prediction
* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature engineering
* Classification model training
* Model evaluation
* Passenger satisfaction prediction/inference
* Interactive frontend and backend application
* Testing and validation workflows
* Analysis of factors influencing passenger satisfaction

## Machine Learning Process

The machine learning component follows an end-to-end workflow:

1. Load and inspect the dataset.
2. Perform data cleaning and preprocessing.
3. Conduct exploratory data analysis.
4. Perform feature engineering.
5. Train classification models.
6. Evaluate model performance.
7. Generate passenger satisfaction predictions.
8. Analyze factors affecting passenger experience.
